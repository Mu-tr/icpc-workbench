# Windows 一键启动脚本设计

## 目标

在项目根目录提供 `start.bat`，让 Windows 用户双击即可完成环境检查、首次依赖安装、前后端启动和浏览器打开。

## 启动流程

1. 将工作目录切换到脚本所在的项目根目录，避免从快捷方式或其他目录启动时路径错误。
2. 检查 `node` 和 `npm` 是否可用。
3. 检查 Node.js 版本是否至少为 22.16；不满足时显示中文提示并停止。
4. 当根目录缺少 `node_modules` 时运行 `npm install`；失败则显示错误并停止。
5. 在后台等待本地前端地址可访问，然后使用系统默认浏览器打开 `http://localhost:5173`。
6. 在当前窗口运行 `npm run dev`，保留服务日志；用户关闭窗口或按 `Ctrl+C` 时停止服务。

## 错误处理

- 缺少 Node.js、npm、依赖安装失败或开发服务退出时，显示明确的中文说明。
- 出错后暂停窗口，避免双击运行时错误信息一闪而过。
- 浏览器等待逻辑不得阻止开发服务启动；即使自动打开失败，用户仍可手动访问地址。

## 验证

- 静态检查批处理语法和路径处理。
- 确认当前 Node.js 版本满足项目要求。
- 安装依赖，并验证 `npm run dev` 能同时启动 server 与 client。
- 确认 `http://localhost:5173` 可访问后停止测试进程。
